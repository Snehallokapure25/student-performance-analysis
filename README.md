# Student Performance Analysis 📊

A beginner-friendly Data Science project using Python and Pandas to analyze student academic performance.

## 📌 About the Project

This project analyzes the marks of students across different subjects and uses Python to calculate statistics and create visualizations.

## 🎯 Objectives

- Analyze student marks
- Calculate average marks for each subject
- Find the highest marks
- Understand basic data analysis using Pandas
- Visualize results using Matplotlib

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- GitHub
